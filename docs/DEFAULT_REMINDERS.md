# v0.0.39 기본 개인 재촉

새 개인 설정은 공개 원씽 채널에서 기본 켜짐, 한국 시간 평일11:00 원씽·20:00 후기다. 비공개 QA 채널 기본값은 꺼짐을 유지한다. 실제 원씽 채널의 신규 입장 이벤트로 회원을 등록하고 예약을 갱신한다. 기존 설정이 있는 회원의 재입장 이벤트는 설정을 덮어쓰지 않는다.

- `preference_source`: legacy(과거 값, 선택 의도 미상), default(새 기본값), user(본인이 변경).
- `eligible_from`: 신규 설정 생성 다음 한국 날짜부터 재촉 가능. 토·일은 생성·claim 양쪽에서 제외하므로 금요일 신규 회원은 월요일부터다. 가입 당일에는 지난 시간대 재촉을 받지 않는다.
- 원씽 없음일 때 등록 안내, 원씽 있고 후기 없음일 때 후기 안내. 완료 표시만으로 후기 제출을 가정하지 않는다.
- 휴식·제출·중지·주말·22시~08시에는 보내지 않는다. DB 발송 대상 생성과 발송 직전 claim에서 다시 검사한다.
- 기존 종류별1일1회 키를 유지한다. 무응답을 실패/퇴장으로 처리하지 않는다. 카카오·문자 발송 동의와 무관한 Slack 내부 안내다.

## 기존 설정 처리

과거 DB에는 기본 꺼짐과 명시적 중지를 구분한 이력이 없다. 최초 이관 때 기존 꺼짐은 확인 전 보존했다. 2026-09-12 사용자가 현재 회원 전체 켜짐과 즉시 재촉을 명시해 원씽 채널 실제 회원6명을11시·20시 켜짐으로 전환했다. 이전 설정과 관리자 변경 사유는 별도 기록으로 보존했다. 기존 enabled=true 또는 기본10/18과 다른 시각은 user로 보존하며, 변경을 직접 저장할 때도 user로 표시한다. 새 기본값 적용이 기존 opt-out을 재활성화하지 않는다. 운영 원씽 채널의 실제 회원을 확인해 기존 설정이 없는 회원만 기본값으로 등록했다.

최초 적용은 기본 켜짐1명·기존 꺼짐5명이었으며, 2026-09-12 추가 지시 후 현재6명 모두 켜짐이다. 이후 본인이 끄면 그 선택을 다시 존중한다. 이번 즉시 수동 재촉은 자정 직후이므로9/11 기록을 기준으로 원씽 누락1명·후기 누락4명에게 한 번 전송하고 완료·후기 제출자1명은 제외했다. 주말·조용한 시간의 정기 발송 규칙은 변경하지 않았다.

## 이관·검증

008 migration은 기존 preferences 전체를 archive에 저장한 뒤 열과 wrapper를 트랜잭션으로 추가한다. 기존006/007은 수정하지 않는다. 운영 dump도 먼저 확보했다. `qa/default-reminders.mjs`는 기본11/20·다음날·weekend/quiet·봇/탈퇴·휴식/제출·종류별 한 번·명시적 중지 보존을 SQL로 검증한다. `qa/reminder-enrollment.mjs`는 일반 회원의 원씽 채널 입장만 등록하고 예약을 갱신하는지 검사한다.

원씽 채널을 떠난 뒤의 채널 소속 해제 처리는 별도 동기화 과제다. 현재 봇/Slack 삭제 상태는 원장의 확인값을 사용하며 지속적인 디렉터리 동기화까지 구현된 것은 아니다. 임시 채널 읽기 실패를 회원의 opt-out으로 해석하지 않는다.
