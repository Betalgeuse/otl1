# 로드맵


## 출시 상태와 판단 경계

현재 운영 기능 기준은 v0.0.55입니다. 모든 v0.0.56–v0.0.70는 미출시 계획이며, 배포·Slack Web·브라우저 관찰 영수증이 같은 정확한 SHA에 묶이기 전에는 출시로 바꾸지 않습니다.

- 회원 자격은 확인된 기존 회원의 소개로만 시작합니다. 소개자는 입장 경로의 출처일 뿐 승인·한도 변경·지원자 정보 접근 권한이 없습니다. 공개 Slack 초대 링크나 자동 초대는 만들지 않습니다.
- 휴면은 Slack 계정·채널 접근·과거 기록을 지우거나 강퇴하지 않습니다. 현재 시즌을 보존하고, 휴면 뒤에는 새 현재 날짜 ONE THING만 참여 자격을 되돌립니다.
- 후보는 공통 목표 프롬프트와 완전한 회원 스냅샷이 모두 성공한 관측 평일만 셉니다. 주말, 온보딩 전, 승인 유예, 수집 실패, 미해결 정정은 세지 않습니다.
- 공개 사이트의 비소속자 문의는 운영자만 보는 선택적 문의입니다. 문의는 가입·소개·할당량 예약·Slack 초대가 아니며, 확인된 소개와 수동 Slack 초대의 경계를 유지합니다.
