# 로드맵


## 판단이 필요한 것

- 자기소개: 현재 소개는 180자 이내로 공개하고 이전 내용은 회원에게 노출하지 않습니다. 소개 내용을 관련 사람 연결에 사용할 별도 동의는 아직 미정입니다.
- 초대: 별도 초대권·월별 장수·웹 발급 기능은 만들지 않습니다. 사람 대 사람으로 소개받아 입장하는 원칙은 유지하되 소개자는 권한이나 의무가 아니라 관계 출처로만 분리합니다.
- 웹사이트: 회원 계정·초대장·프로필 관리 없이 커뮤니티 소개, 운영원칙, 참여 방법과 문의 경로를 보여주는 공개 페이지로 한정합니다. 공개 가입 링크를 둘지는 별도 입장 정책입니다.
- 인원·제외·복귀·수익화: 정원, 휴식 예외, 유예, 복귀, 제공 가치와 보상 재원을 확정해야 합니다.30명·50명·4주 관찰은 이전 제안입니다.
- shareinfo 사람 연결: 정보가 바로 도움이나 ONE THING으로 이어진다고 가정하지 않습니다. 자기소개 관리 뒤에 다시 검토하며 게시량·인기 점수는 보상하지 않습니다. 근거와 보류 이유는 [설계 일지](research/DESIGN_JOURNAL.md)를 따릅니다.
