# 로드맵

아래는 **미출시 계획**입니다. 출시한 결과는 [업데이트 이력](UPDATE_HISTORY.md)에만 기록합니다. 이번 문서 정리로 순서·번호·완료 조건은 변경하지 않았습니다.

## 판단이 필요한 것

- 초대 수: 과거 월1장 요구와 안내글의2명 규칙을 어떻게 적용할지 확정해야 합니다.
- LinkedIn: 회원 프로필 연결인지 초대 후보 담당 배정인지 확인이 필요합니다. 홈페이지가 선행해야 하는지는 해당 기능별로 판단합니다.
- Silo: 소속·이동·복수 소속과 경쟁 지표를 정해야 합니다. 회사·초대자·팀을 같은 관계로 가정하지 않습니다.
- 인원·제외·복귀·수익화: 정원, 휴식 예외, 유예, 복귀, 제공 가치와 보상 재원을 확정해야 합니다.30명·50명·4주 관찰은 이전 제안입니다.
- shareinfo 사람 연결: 구체적인 성공 장면과 태깅 기준·빈도·정보 범위가 미정입니다. 자동 연결을 구현한 것으로 안내하지 않습니다.
