## 2026-09-17 미출시 회원 기준 일괄 수집 수정

현재 daily-scrum의 완전한 Slack 회원 목록을 수집 시점마다 확인하고, 이탈·삭제·봇 계정을 제외한 목표·후기 대상자를 채널당 한 메시지로 묶는 구현 후보를 추가했습니다. 일부 회원 조회 실패 시에는 멘션과 비활성화를 모두 중단하며, 사용자 설정과 과거 기록은 보존합니다. migration 023, 폐기 가능한 PostgreSQL, 합성 Slack 검증과 비공개 관리 채널의 `데일리스크럼 수집 테스트` 버튼까지 구현했습니다. 버튼은 저장된 공개 채널 시각을 바꾸지 않고 같은 현재 회원 수집 경로를 실행하며 인원·배치 수만 비공개로 돌려줍니다. 운영 migration·배포·Chrome Slack Web 관찰 전이므로 출시 버전 표에는 넣지 않았습니다.

완료 상태가 없는 유효한 후기는 버튼 응답을 기다리지 않고 먼저 저장하고 잔디와 반응을 갱신하도록 변경했습니다. 완료·부분 완료·미완료·휴식은 같은 공개 스레드에서 버튼 또는 짧은 자연어로 선택할 수 있습니다. 질문 전송 실패는 durable delivery로 재시도하며 후기 저장을 되돌리지 않습니다. 중복 이벤트, 오래된 버튼, 다른 사용자 선택은 기록을 다시 쓰지 않습니다. 이 항목은 코드와 합성 QA까지만 완료했으며 운영 배포와 실제 Slack Web QA 전입니다.
