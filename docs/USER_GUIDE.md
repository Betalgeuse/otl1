# ONE THING 사용 안내

**ONE THING**은 오늘 최우선순위로 가장 먼저 해결할 중요한 일 한 가지를 정하고, 해낸 만큼과 느낀 점을 함께 남기는 공간입니다. 이 문서는 v0.0.53까지의 회원용 동작을 안내합니다.

[문서 목록](README.md) · [운영 안내](OPERATIONS.md) · [구조와 데이터](ARCHITECTURE.md) · [개발 안내](DEVELOPMENT.md)

## 자기소개

`all-self-introduction`에 들어오면 봇이 새 회원을 멘션하고 **자기소개 쓰기**와 **모두 보기**를 보여줍니다. 소개는 줄바꿈을 포함해 총 180자 이내로 자유롭게 적습니다. LinkedIn과 웹사이트·GitHub·포트폴리오 같은 기타 공개 정보는 선택 사항이며 자기소개와 함께 이 채널에 공개됩니다.

**모두 보기**를 누르면 현재 회원들의 자기소개와 공개한 LinkedIn을 본인에게만 모아서 보여줍니다. 본인 소개를 다시 열면 기존 내용이 채워지고, 수정하면 새 글을 만들지 않고 기존 공개 메시지가 바뀝니다.

운영자가 채널에 `자기소개 현황` 또는 `자기소개 미작성자 안내`라고 쓰면 아직 소개가 없는 채널 회원만 공개 멘션합니다. 일반 회원이 `자기소개 목록` 또는 `자기소개 모두 보기`라고 쓰면 같은 비공개 목록을 볼 수 있습니다.

## 등록하고 하루를 돌아보기

`daily-scrum` 채널이나 해당 날짜 안내 스레드에 자연어로 남겨주세요. 봇 멘션은 필수가 아니며, `/one` 명령은 사용하지 않습니다. 입력할 때는 ‘원씽’이라고 써도 됩니다.

| 하고 싶은 일 | 입력 예 |
| --- | --- |
| 오늘 목표 등록 | `오늘 원씽은 발표 자료 초안 완성하기` |
| 완료 상태 남기기 | `오늘 목표 완료했어요` |
| 일부 진행과 후기 남기기 | `후기: 부분 완료. 초안 절반을 썼고 내일 이어갈게요.` |
| 휴식하기 | `오늘은 쉬었어요` |
| 현재 기록 확인 | `내 상태` |

**완료 상태와 후기 제출은 별개입니다.** `후기: 완료.`처럼 상태만 쓰면 완료만 반영합니다. 짧더라도 실제 돌아본 내용을 남겨야 후기 제출로 인정합니다. 다 끝내지 못했어도 후기를 남길 수 있습니다.

기존 목표가 있는 날에 명확한 첫 후기를 쓰면 자동 저장합니다. 예를 들어 아래 형식에서 날짜가 오늘이라면 완료와 후기 본문을 함께 읽습니다.

```text
후기:
9/14: 완료. 중요한 일부터 시작하니 오후에 마음이 편했어요.
```

뜻이 불분명하거나 상태가 서로 모순되면 확인을 요청할 수 있습니다. `완료 예정`, `거의 완료`, 질문이나 가정은 완료 보고로 취급하지 않습니다. 기록 확인이 필요할 때는 **본인에게만 보이는 메시지의 날짜와 내용을 확인한 뒤 버튼을 눌러주세요.**

## 지난 목표·후기 수정하기

날짜와 바꿀 내용을 함께 말해주세요.

```text
9/13 목표를 책 20쪽 읽기로 수정해줘
어제 목표 달성했어. 후기: 중요한 일부터 하니 마음이 편했다.
2026-09-13 후기 수정해줘. 후기: 절반 진행했고 내일 이어갈게.
```

- 목표 내용만 수정하면 기존 완료 여부·후기·휴식은 유지합니다.
- 후기만 수정하면 완료 여부는 유지합니다. 완료도 바꾸려면 함께 말해주세요.
- 과거 날짜 변경, 기존 후기 덮어쓰기, 휴식과 수행 상태의 충돌은 본인 확인을 거칩니다. 확인하지 않으면 저장하지 않습니다.
- 확인창을 연 뒤 기록이 다시 바뀌었다면 오래된 버튼으로 덮어쓸 수 없습니다. 새로 요청해주세요.

일반 수정에는 `YYYY-MM-DD`, `M/D`, `M월D일`, `어제`, `그제`를 사용할 수 있습니다. 명시적 후기 헤더에는 `YYYY.MM.DD`, `M.D`도 지원합니다. 연도가 헷갈릴 수 있으면 연도까지 적어주세요. 여러 날짜를 한꺼번에 지정하거나 잘못된 날짜·미래 날짜·기록이 없는 날짜를 지정하면 저장하지 않습니다.

날짜 없이 답글을 달면 현재 대화에 연결된 날짜를 사용합니다. 과거 안내 스레드에 오늘 답해도 그 과거 날짜의 기록입니다. ‘이전 목표’처럼 대상이 불명확하면 날짜를 다시 묻습니다.

## 잔디와 개인 설정

잔디는 등록·완료 상태를 색으로 보여줍니다. **과거 기록을 수정해도 잔디는 오늘까지 표시**합니다. 새 잔디를 게시하면 봇이 관리하는 이전 카드의 이미지와 버튼을 제거하고 원문과 댓글은 보존합니다.

`내 상태`에서 본인에게만 보이는 관리 메시지를 열 수 있습니다. 완료·휴식 등의 확인, 되돌리기, 개인 알림 설정, 색상 변경도 당사자에게만 표시합니다. Slack의 임시 메시지가 사라지면 `내 상태`나 `알림 설정`을 다시 입력하세요.

색은 **내 상태 → 색상 변경 → 미작성·작성·완료 색 선택 → 저장**으로 바꿉니다. HEX 색상 입력과 기본색 복원도 지원하며 이후 잔디에 적용됩니다.

잔디 조회나 기록 저장 후에는 미정리된 이전 평일 기록을 안내할 수 있습니다. 이미 쓴 후기는 다시 요구하지 않고, 완료 여부나 후기 중 빠진 항목만 요청합니다. 휴식일과 주말은 제외하며, 답이 없다고 자동 미완료 처리하지 않습니다.

## 알림과 주말 참여

`알림 설정`에서 본인의 안내 시각과 수신 여부를 바꿉니다. 정확한 기본 시각·횟수·제외 조건은 [운영 가이드](OPERATIONS.md#안내와-재촉) 한 곳에서 관리합니다.

**주말은 선택이에요.** 멘션 없이 참여할 수 있고 쉬어도 괜찮습니다. 목표를 등록하거나 완료한 주말만 잔디에 표시하며, 미참여 주말은 회색 칸 없이 숨깁니다. 남은 칸의 날짜와 DAY 번호는 유지합니다.

## 환영과 동료 축하

환영과 첫 기록 축하는 townhall에서, 신규 회원용 안내는 welcome-start-here에서 확인합니다. 직접 동료에게 보내는 샤라웃도 사용할 수 있습니다. 봇의 자동 축하와 회원이 직접 보내는 응원은 구분됩니다. 자세한 게시·안내글 관리 규칙은 [운영 가이드](OPERATIONS.md#환영과-첫-기록-축하)를 따릅니다.

## 사용법이 궁금할 때

`등록은 어떻게 해?`, `주말도 필수야?`, `Slack에서 내가 만든 section이나 Starred가 다른 사람에게도 적용돼?`처럼 물어볼 수 있습니다. 멘션 없는 질문도 처리합니다.

현재 답변 범위는 **ONE THING 사용법, 주말 운영, Slack 섹션·Starred 관련 안내**입니다. 모든 주제를 검색해 답하는 기능은 아니며, 질문에 답하는 과정에서 목표나 개인 설정을 변경하지 않습니다.
