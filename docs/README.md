# 문서 안내

ONE THING 문서는 **현재 동작**, **앞으로의 계획**, **과거 근거**를 구분합니다. 현재 운영 기준은 **v0.0.50**입니다.

| 알고 싶은 내용 | 읽을 문서 |
| --- | --- |
| 목표·후기를 남기고 고치는 방법 | [사용 가이드](USER_GUIDE.md) |
| 채널 역할, 알림, 환영, 관리자 작업 | [운영 가이드](OPERATIONS.md) |
| 봇 처리 흐름과 DB 원본 | [시스템 구조](ARCHITECTURE.md) |
| 설치·테스트·배포·공개 코드 관리 | [개발 가이드](DEVELOPMENT.md) |
| 우리가 지키는 기준 | [제품 원칙](PRODUCT_PRINCIPLES.md) |
| 이론을 바탕으로 고민한 과정과 판단 변화 | [설계 일지](research/DESIGN_JOURNAL.md) |
| 다음에 구현할 항목과 미정 정책 | [로드맵](ROADMAP.md) |
| 출시한 버전별 결과 | [업데이트 이력](UPDATE_HISTORY.md) |

## 문서 관리 규칙

- 같은 사실은 한 문서에서만 관리합니다. 다른 문서는 복사하지 않고 링크합니다.
- 사용법에는 코드·QA 영수증을, 출시 이력에는 전체 사용법을 반복하지 않습니다.
- 미래 기능은 로드맵에만 두며 현재 기능처럼 설명하지 않습니다.
- 과거 기록은 [보관 문서](archive/README.md), 벤치마크·사업 가설은 [조사 자료](research/README.md)에 둡니다. 현재 운영 지침으로 사용하지 않습니다.
- 문서 정리는 제품 기능 출시가 아닙니다. 버전을 추가하거나 기존 번호를 바꾸지 않습니다.
- 이론을 바탕으로 운영·제품 방식을 고민할 때마다 [설계 일지](research/DESIGN_JOURNAL.md)에 날짜, 근거와 한계, 판단 변화, 확정 여부, 검증할 사항을 남깁니다. 제안을 확정 정책으로 취급하지 않습니다.
