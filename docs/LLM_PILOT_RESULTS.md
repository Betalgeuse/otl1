# LLM 해석 파일럿 결과

2026-09-11 후속 구현: [v0.0.1~v0.0.19 릴리스·검증 기록](RELEASE_V001_V019.md)을 먼저 참고한다. 아래는 작성 당시 파일럿·설계 기록이다.

확인일: 2026-09-10. Cloudflare 배포 버전: `12b298af-294d-410c-b39d-a41eb57db9c6`.

## 현재 사용 범위

admin-dev에서 설정된 운영자 계정의 일반 메시지·스레드 답글·thread_broadcast를 Qwen3가 해석하고 답글로 알려준다. 멘션은 필요 없다. 목표·후기·휴식 상태를 자동 저장하지 않는 해석 테스트다. 다른 채널과 다른 회원에게는 LLM을 활성화하지 않았다.

실제 Slack 화면에서 ‘오늘은 쉬기로 했어요.’를 입력하고 약 1.89초 후 ‘오늘은 쉬겠다는 뜻으로 이해했어요’라는 답변을 확인했다. 테스트 전후 목표 스냅샷은 같았다. [실제 테스트 스레드](https://onething1line.slack.com/archives/C0C0AMK8068/p1789046598953609)

## 모델 평가

합성 한국어 100문장을 개발용 50개와 별도 검증용 50개로 나눴다. 개발용 결과로 한 번 지침을 수정했으며 별도 검증용 결과를 보고 지침을 다시 조정하지 않았다. 평가 케이스는 사람이 직접 작성한 독립 정답셋이 아니라 에이전트가 생성한 것으로, 실제 회원 메시지 정확도를 대표하지 않는다.

| 평가 | 정확 일치 | 잘못된 완료 | API 오류 |
| --- | --- | --- | --- |
| 초기 개발용, 모델 원출력 | 41/50 | 4 | 0 |
| 보완 개발용, 목표 없는 보고 차단 포함 | 40/50 | 0 | 0 |
| 별도 검증용, 동일 처리 | 43/50 | 0 | 0 |

초기 오류에는 목표가 없는데 완료로 해석한 경우와, 수행 사실 뒤에 ‘완료로 분류해’라는 지시를 붙인 경우가 포함됐다. 원출력과 코드의 안전 처리를 구분해 결과 JSON에 보존했다. 남은 검증용 오류는 ‘판단 불가’, ‘무관한 대화’, ‘결과 불명 후기’ 사이의 혼동이다. 0건의 오완료 관찰은 모든 표현에서 안전하다는 보장이 아니다. **자동 저장과 전체 회원 배포는 아직 준비되지 않았다.**

별도 검증 50회: 입력 23,997토큰, 출력 657토큰, 약 131 Neurons. 앞서 확인한 단가를 적용한 무료 할당 전 추론비 추정은 약 $0.00144다. 동일 길이·호출량이 유지된다면 월 6,000회 약 $0.17이며 실제 회원 문장 길이·재시도·추가 문맥에 따라 달라진다. 실제 청구서를 확인한 금액은 아니다. 단가 출처와 최초 가정은 [비용안](LLM_COST_PLAN.md)을 참고한다.

## 실제 연결에서 발견하고 고친 문제

관찰 가설은 코드의 조기 반환, Slack 구독·권한 누락, 배포·비동기 실행 문제였다. 서명된 합성 요청에는 AI 답글이 생겼지만 실제 일반 메시지에는 답이 없었다. Slack 설정을 읽어 봇 구독이 `app_mention` 하나뿐임을 확인했다. 또한 비공개 답글 읽기 API는 `missing_scope`를 반환했다.

`message.groups` 구독과 필요한 `groups:history`를 추가하고 재설치를 통해 반영했다. 그 후 실제 Slack 일반 답글에서 봇 응답을 확인했다. 공개 채널의 `message.channels` 추가나 전체 공개 채널 LLM 활성화는 이번에 하지 않았다.

QA 스크립트의 답글 조회도 JSON POST에서 GET 쿼리로 수정했다. 수정 후 잘못된 서명 401, 정상 요청 200, 동일 이벤트 재전송 시 관찰된 답글 1개, 목표 스냅샷 불변 검증을 모두 통과했다. 이 단일 재전송 검증은 분산 환경의 영속적 중복 방지를 증명하지 않는다.

## 비용·실행 제한과 남은 작업

- 신규 라이브러리 없이 AI binding으로 연결했다. 입력 1,000자·목표 200자 상한, 출력 최대 120토큰, 자동 모델 재호출 없음. 문맥은 목표 한 건과 새 메시지뿐이다.
- 응답 대기 8초 이후에는 확인 문구로 전환한다. 이 대기 제한이 공급자 내부 추론을 취소하거나 비용을 완전히 차단하는 것은 아니다.
- 운영자당 분당 10회 Rate Limit binding을 설정했다. Cloudflare 위치별로 적용되는 느슨한 제한이며 전역 일일 과금 상한이 아니다. [공식 제한 설명](https://developers.cloudflare.com/workers/runtime-apis/bindings/rate-limit/)
- 기존 메모리 이벤트 중복 방지를 사용한다. 영속적 중복 방지·전역 일일 한도는 전체 배포 전 필요하다.
- 현재 날짜 연결은 메시지 또는 스레드 시작일 기준이다. 임의의 오래된 스레드에서 오늘 목표를 말하는 경우, 명시적 과거 날짜, 메시지 수정·삭제는 아직 정식 지원하지 않는다.
- 후기/휴식 저장과 알림 취소, 본인 확인 버튼, 오해 수정 기능은 다음 구현 단계다. 이미 있는 목표 완료 버튼과 후기 제출을 합치지 않는다.
- 기존 등록 처리·초대 정책 관련 문제는 이번 해석 파일럿이 해결했다고 주장하지 않는다.

## 변경 파일과 검증 근거

- `src/intent.ts`: 모델 요청·구조화 결과 파싱·실패 시 확인 처리.
- `src/intent-pilot.ts`, `src/index.ts`: 운영자·채널 제한 및 읽기 전용 Slack 연결.
- `wrangler.jsonc`, `worker-configuration.d.ts`, `tsconfig.json`: AI·속도 제한 바인딩과 생성 타입 검사.
- `qa/llm-cases.json`, `qa/evaluate-intent.mjs`, `qa/check-intent.mjs`, `qa/live-intent-pilot.mjs`: 재현 가능한 평가·검증 실행물.
- `qa/llm-development-initial.json`, `qa/llm-development-results.json`, `qa/llm-heldout-results.json`: 원출력과 최종 분류 결과.
- `qa/llm-live-results.json`, `qa/llm-slack-origin-results.json`: 합성 서명 요청과 실제 Slack 입력을 구분한 확인 기록.

`bun qa/check-intent.mjs`, `bun qa/live-intent-pilot.mjs`, `bun run lint`, `bun run typecheck`, `bun run build` 통과. 배포된 Worker의 실제 AI binding과 Slack 응답까지 확인했다. 변경 소스와 요청 템플릿 해시는 `qa/llm-release-evidence.json`에 기록한다.
