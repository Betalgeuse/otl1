# v0.0.32 주말 선택 참여

한국 시간 토요일·일요일은 선택 참여일이다. 채널이나 해당 날짜 스레드에 자연어로 원씽을 남기면 되고, 봇 멘션은 필수가 아니다. 평일 등록 방식과 같으며 주말 미참여는 실패가 아니다.

- 오전 공통 안내만 하루 한 번 보낸다. 주말 안내에는 전체·개인 멘션을 넣지 않는다.
- 오후 공통 후기 안내와 개인 원씽/후기 재촉을 보내지 않는다. 주말에 참여했어도 재촉하지 않는다.
- 월요일 이후 이전 날짜 안내에서도 주말은 제외한다.
- 참여한 주말은 등록·완료 색을 평소처럼 표시한다. 미참여한 지난 주말은 잔디에 O와 선택 참여 설명으로 구분한다. 날짜 순서와4/8칸 구조는 유지한다.
- 주말에도 본인이 완료·부분 진행·후기·휴식을 남기면 기존 확인·수정 로직을 적용한다. 오늘 답변했다고 다른 날짜에 저장하지 않는다.

안내: ‘주말 원씽은 선택이에요!!! 함께하고 싶다면 가장 먼저 해보고 싶은 중요한 일 한 가지를 이 스레드나 채널에 편하게 남겨주세요. 멘션 없이 적어도 돼요. 푹 쉬어도 좋아요!!!’

검증: `qa/weekends.mjs`는 토·일/월요일 경계, 오전 한 번·멘션 없음·저녁 및 개인0건·이전 날짜 제외·선택 표시를 검사한다.4칸·8칸·주말 참여 이미지 시각 검사도 수행했다. 실제 admin-dev에서 토요일을 기준으로 예약 함수를 실행한 결과 오전1건·저녁0건·개인0건을 확인하고, 관리자 프로필로 멘션 없이 등록 흐름을 조작했다. 이는 토요일 시각을 넣은 비공개 QA이며 실제 다음 주말의 자연 발생 예약은 아직 관측하지 않았다.

공통 안내가 비활성인 채널에는 주말 안내도 보내지 않는다. Durable Object가 주말 저녁에 깨어날 수는 있지만 발송 함수가 전송을 건너뛴다.
