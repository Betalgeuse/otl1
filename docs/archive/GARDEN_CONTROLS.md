# 당사자 전용 조작과 잔디 갱신

## v0.0.35 당사자 전용 확인·설정

완료·부분 진행·미수행·휴식·후기 확인 선택지는 `chat.postEphemeral`로 해당 사용자에게만 보낸다. 채널에 공개하는 잔디 카드에는 조작 버튼을 넣지 않는다. 되돌리기·현재 상태·개인 알림 설정·색상 변경은 별도의 당사자 전용 관리 메시지로 제공한다.

개인 알림 설정 화면과 저장/중지 결과도 당사자 전용이다. 기존 /one의 공개 공유 카드에서는 완료/색상 설정 버튼을 제거한다. 개인 재촉 글에는 공개 중지 버튼 대신 ‘알림 설정’이라는 자연어 진입 안내를 둔다. 회원 누구나 사용할 샤라웃 제안은 공개로 유지한다. 관리자 기능은 기존 비공개 admin 채널과 지정 관리자 검사를 유지한다.

Slack ephemeral은 활성 사용자에게만 보이며 세션·새로고침 이후 사라질 수 있다. 사라지면 ‘내 상태’ 또는 ‘알림 설정’으로 다시 열 수 있다. 비공개 표시가 서버의 소유자 검사를 대체하지 않으며 다른 회원이 조작 값을 사용해도 거절한다.

## v0.0.36 잔디 색상 변경

‘내 상태’ → 나에게만 표시되는 ‘색상 변경’ → 미작성/작성/완료 색상 선택 또는 HEX 직접 입력 → 저장. 기존 팔레트 검증과 기본색 복원을 재사용한다. 다른 사람의 팔레트를 변경할 수 없으며 모달 작성자·채널·대상 날짜를 확인한다. 팔레트는 회원 설정이므로 이후 생성되는 그 회원의 잔디에도 적용된다.

## v0.0.37 새 잔디 게시와 옛 이미지 제거

회원·채널에 대해 봇이 관리 기록을 보유한 이전 잔디는 새 게시 성공 후 이미지/버튼만 제거한다. 원문과 댓글을 보존하기 위해 전체 메시지를 삭제하지 않는다. 날짜가 바뀌어도 새로 조회한 잔디를 새 메시지로 올린다. 실제 목표/후기 데이터는 삭제하지 않는다.

채널 Durable Object에서 갱신을 직렬화하고 실행 시 최신 날짜별 상태를 다시 읽는다. 새 메시지 발송이 실패하면 옛 이미지를 제거하지 않는다. 옛 이미지 제거가 실패하면 경고를 기록하고 다음 조회에 다시 시도한다. 발송 후 기록 저장 전에 프로세스가 중단되는 외부 API 원자성까지 보장하는 것은 아니다.

이번 변경 이전의 조회 전용 카드처럼 게시물 관리 기록이 없는 메시지는 자동 전체 청소 대상이 아니다. 이력에 등록된 기존 변경 카드와 이번 버전부터 게시한 카드를 관리한다. 개인 ephemeral 메시지는 공개 게시물 이력이 아니므로 이전 임시 조작창이 세션 안에 남을 수 있지만 소유자·최신 revision 검사를 유지한다.

## 검증

`qa/private-controls.mjs`, `qa/garden-publication.mjs`: 본인/타인 경계, ephemeral 수신자, 모달 소유자, HEX·팔레트 저장·갱신 호출, 공개 카드에 actions 없음, 새 발송 실패 시 옛 이미지 유지, 메시지 텍스트 보존을 검증한다.

admin-dev 실제 사용자 계정으로 ‘내 상태’ → Only visible to you → 색상 변경 → 완료 보라색 저장을 수행했다. 같은 스레드의 관리 대상 잔디가 새 메시지 한 건만 이미지를 유지하고 이전 이미지·버튼이 제거됨을 Slack API로 확인했다. 완료·휴식 확인창의 Only visible to you 표시를 확인했다. 원래 팔레트는 QA 후 복원한다.

공식 근거: https://docs.slack.dev/reference/methods/chat.postEphemeral/ 및 https://docs.slack.dev/reference/methods/chat.update/
