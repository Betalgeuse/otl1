*OT1L 업데이트 계획 · 2026-09-10*

중요한 한 가지를 실천하고, 나를 믿고 초대한 지인과 함께 성장할 수 있는 커뮤니티를 만들고 있습니다. 앞으로 이 채널에서 업데이트와 운영 계획을 공유하겠습니다.

*현재 방향*
• 지금은 무료 운영입니다. 이후 운영 비용과 보상을 감당하면서 운영자에게도 이익이 남는 구조를 검토합니다. 유료화 일정·가격은 정하지 않았습니다.
• 지인의 실제 실천이 초대자의 혜택으로도 이어지는 보상을 설계합니다. 구체적인 보상은 아직 미정입니다.
• 자연어 이해는 admin-dev에서 제한적으로 테스트했습니다. 확인 버튼과 실제 상태 저장은 다음 구현 항목입니다.

*다음 업데이트 목록 — 순서 검토 중*
1. 자연어 입력 → 본인 확인 → 목표·후기·휴식 상태 저장 및 수정
2. 회원 상태 관리, 필요한 사람에게만 안내, 휴식·제출 후 추가 알림 중단
3. 별도 홈페이지에서 초대장 발급·수락, 카카오톡 또는 LinkedIn 정보와 초대 관계 관리
4. Silo 구성원 매핑, 최신 welcome 가이드, 첫 참여 적응 지원
5. 장기 미참여 안내·유예·제외·복귀 흐름
6. 지인 성취 보상과 유료 서비스 모델

*무료 운영 규모 — 확정 전 제안*
• 1단계: 활성 회원 최대 30명으로 기본 기능과 운영 부담 확인
• 2단계: 최대 50명으로 확장하고 4주간 참여·지원 비용·관리 시간을 관찰
• 이후: 실제 제공 가치와 수익성을 확인한 뒤 유료 상품 검토
인원수는 논의를 위한 초안입니다. 특정 인원에 도달했다고 자동으로 유료화하지 않으며, 기존 회원 적용 조건도 미정입니다.

*아직 시행하지 않는 정책*
• 미참여 회원의 자동 제외는 기준·안내·유예·복귀 방법을 정한 뒤 검토합니다. 현재 자동 퇴장은 없습니다.
• ‘오늘 쉬기’로 하루 참여를 마무리하는 방향을 반영하며, 휴식·목표 미완료·후기 미제출을 구분하겠습니다.
• 카카오톡/LinkedIn 정보의 입력 방식과 공개 범위는 미정입니다. 연락처 등록과 알림 수신 동의는 별도로 다룹니다.

운영 정책은 확정된 내용과 검토안을 구분해서 이곳에 계속 업데이트하겠습니다.
