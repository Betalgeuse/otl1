# Townhall 운영 연결

확인일: 2026-09-11. 배포: `052a3bd0-c873-4098-87bf-0255bf95a5ab`.

## 현재 설정

- daily-scrum은 매일 한국 시간 10:00 원씽·18:00 후기 안내를 유지한다. 이 작업 시점의 다음 안내는 2026-09-11 10:00이다.
- 업데이트 게시 대상은 실제 `all-townhall`이다. 봇을 채널에 연결해 새 게시물의 피드백 답글을 수신할 수 있게 했다.
- 운영은 admin-dev에서 한다. `업데이트 관리` → 버전 선택 → 내용·대상 미리보기 → `townhall에 게시` 순서다.
- 실제 공지는 이번에 게시하지 않았다. 게시 동작을 실행하기 전에는 미리보기만 남는다.
- `피드백 보기`는 admin-dev의 테스트 의견 대신 실제 townhall에 저장된 버전별 피드백을 조회한다. 일반 townhall 잡담은 목표로 자동 등록하거나 피드백으로 수집하지 않는다.

## 공개 전 검사

미리보기에는 버전·본문·게시 대상·30분 유효기간을 저장한다. 게시할 때 작성자·검증 완료 여부와 함께 다시 확인한다. 예전 QA 버튼의 버전 문자열만으로는 게시할 수 없다. 대상이나 본문이 바뀌거나 만료되면 새 미리보기가 필요하다. 동일 버전은 해당 게시 채널에 한 번만 발행한다.

실제 화면에서 여러 버전 버튼이 중복 action_id를 사용해 열리지 않는 문제를 발견했다. 하나의 버전 선택 목록으로 바꿔 수정하고 회귀 검사에 추가했다. [Slack action_id 조건](https://docs.slack.dev/reference/block-kit/block-elements/button-element/)

## 검증

- `qa/community-townhall.mjs`: 외부 전송을 가로챈 테스트로 예전 버튼·변경된 대상·만료·다른 작성자 차단, 단일 게시, 회원 피드백 중복 방지, admin에서 townhall 피드백 조회를 확인했다.
- lint·typecheck·빌드/배포 성공.
- 실제 사용자 프로필로 admin-dev에서 버전 선택과 townhall 대상 미리보기까지 확인했다. 공개 게시 버튼은 누르지 않았다.
- 공개 채널의 실제 첫 공지 발행과 실제 회원 피드백 수신은 아직 수행하지 않았다. 공개 전송의 멱등성과 DB 기록 간 네트워크 경합 한계는 이전 릴리스 문서와 같다.
