# 다음 우선순위: 핵심 기록 수정과 신규 안내

후속 구현: 목표·후기 수정은41~42, 원본 기반 가이드 버전·신규 전달은47~48에서 적용했다. 최신 동작은 [TOWNHALL_ONBOARDING.md](TOWNHALL_ONBOARDING.md)를 따른다. 아래는 초기 명세 맥락이다.

2026-09-11 사용자 결정. 현재 배포는 v0.0.49까지다. 목표·후기 자연어 수정은 [구현 명세](NATURAL_RECORD_EDITS.md)를 따르며 나머지 가이드 기능은 계획이다. 이 문서는 v0.0.41~44의 구현 범위이며 완료 보고가 아니다.

## v0.0.41 목표 내용 수정

본인 기록에서 날짜와 현재 목표를 확인한 뒤 내용을 고친다. 기본 진입은 ‘목표 수정’과 기록의 수정 버튼이며, 날짜가 명시되면 해당 날짜를 사용한다. 여러 날짜가 가능한 경우 자동 추측해 다른 날을 수정하지 않는다. 수정 전후와 저장 완료를 표시하고 잔디·기존 저장소를 일치시킨다. 완료 여부·후기·휴식을 내용 수정의 부수 효과로 바꾸지 않는다. 완료 여부까지 바꾸려면 별도 의도를 확인한다. 이전 수정 화면으로 최신 기록을 덮어쓰지 않으며 타인 기록은 수정할 수 없다.

## v0.0.42 후기 내용 수정

본인이 기존 후기의 대상 날짜와 본문을 확인하고 수정한다. ‘후기 수정’이라는 의도는 새 후기나 목표 완료로 처리하지 않는다. 후기 수정으로 첫 후기 축하·완료 축하를 다시 발송하지 않는다. 수정 결과와 되돌리기를 제공하고 당일 이외 날짜 및 동시 수정 충돌도 검증한다. 목표와 완료 여부는 그대로 유지한다.

## v0.0.50 안내글 발행본 관리

확인한 초기 원본: 관리자가 welcome-start-here에 게시한 [안내글](https://onething1line.slack.com/archives/C0C013CF223/p1788918081920379).

원본에는 10시 원씽·18시 후기, All/Chapter/Silo 채널 구조, 지인 초대, Slack 초보 안내가 있다. 본문은 운영자가 관리한다. 기존 ‘현재 2명 초대 가능’과 이전 월1장 정책의 차이를 봇이 임의로 고치지 않는다.

관리자만 admin-dev에서 안내 본문을 편집하고 미리보기 후 발행한다. 안내글을 수정 중인 상태와 실제 전달할 발행본을 분리한다. 발행 시 본문·원본 링크·작성자·발행 시각·관련 제품 버전을 저장한다. 새 발행본을 지정하면 이후 신규 회원은 그 버전을 받는다. 예전에 전달한 글과 발행본은 그대로 보존하고, 새 버전을 기존 회원 모두에게 자동 재발송하지 않는다. 게시 본문을 LLM이 요약하거나 임의로 정책을 바꾸지 않는다.

## v0.0.51 신규 회원에게 최신 안내글 게시

- townhall: 기존 환영 인사와 봇 커스텀 리액션을 유지한다.
- welcome-start-here: 신규 회원을 멘션하며 최신 발행본 **전문을 새 채널 메시지로 게시**한다. 링크만 보내거나 기존 글에 댓글만 다는 것으로 대체하지 않는다.
- 각 채널 입장 이벤트를 독립적으로 처리한다. townhall이 먼저든 welcome이 먼저든 한쪽 기록 때문에 다른 채널의 안내가 누락되지 않는다.
- welcome 채널에 아직 참여하지 않은 회원에게 먼저 게시해 멘션을 놓치게 하지 않고, 해당 채널에 들어온 시점에 전달한다.
- 회원·채널별 전달 기록에 사용한 발행본과 게시물 ID를 연결한다. 중복 이벤트·재입장으로 다시 게시하지 않는다. 발행본 업데이트 중 입장하면 한 발행본의 일관된 본문만 전달한다.
- 아직 발행한 가이드가 없다면 임의 안내를 만들지 않고 관리자에게 알린다. 실패한 전달은 실제 게시 여부를 대조해 중복 없이 복구해야 한다.

검증은 admin-dev에서 관리자 프로필로 편집·발행·수정 충돌·권한 거절을 조작하고, 신규 입장의 두 채널 순서·이벤트 중복·가이드 버전 변경을 재현한다. 공개 안내 재게시와 실제 신규 회원 전달은 승인된 운영 경로에서 확인한다.

## 후순위

v0.0.52~41은 목표 삭제·Slack 지원·첫 적응·Silo 운영이다. 카카오 연락처·발송은 v0.0.59~44, 홈페이지는45~49, 카카오 수신은50~51으로 미뤘다. 홈페이지가 없어도 기존 Slack 회원의 Silo 배정·조회는 먼저 구현할 수 있도록 선행 조건을 분리했다.
