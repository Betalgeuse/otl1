# v0.0.41~42 자연어로 기존 원씽 수정

## 사용 예

- `9/13 목표를 책 20쪽 읽기로 수정해줘`
- `어제 목표 달성했어. 후기: 중요한 일부터 하니 마음이 편했다.`
- `2026-09-13 후기 수정해줘. 후기: 절반 진행했고 내일 이어갈게.`

명시된 날짜를 코드가 해석하고 기존 본인 기록을 찾는다. YYYY-MM-DD, M/D, M월D일, 어제·그제를 지원한다. 월일이 여러 해의 기록과 겹치면 연도를 요청한다. 여러 날짜, 잘못된 날짜, 미래 날짜, 기록 없는 날짜는 저장하지 않는다. 날짜 없이 ‘이전’이라고만 하면 날짜를 다시 묻는다. 날짜 없는 수정은 현재 대화에 연결된 날짜를 사용한다.

Qwen은 목표 제목 수정·후기·완료·부분 진행·미완료·휴식을 구분한다. 제목과 후기는 원문에 있는 문자열만 저장하고 `후기:`가 있으면 그 뒤 전체 문장을 보존한다. ‘목표를 X로 수정’에서 명령문까지 목표로 저장하지 않는다. 명시적인 목표 달성 보고를 후기와 함께 말했을 때 완료 여부를 누락하지 않도록 처리하며 부정·가정·질문은 완료로 승격하지 않는다.

## 확인과 저장

당사자 전용 메시지에 날짜·기존 목표·수정 항목·이전/새 내용·완료 상태를 보여준다. ‘이 날짜 기록 수정’을 눌러야 저장한다. 본인/채널 권한과 현재 revision을 다시 확인하므로 오래된 확인창으로 새 기록을 덮어쓰지 못한다. 취소하려면 누르지 않으면 된다.

목표 제목 수정(v0.0.41)은 기존 날짜별 원본의 내용만 바꾸며 후기·완료 여부·휴식을 유지한다. 새로운 목표 등록 축하를 다시 보내지 않는다. 과거 상태·후기 정정(v0.0.42)은 명시한 날짜의 해당 필드만 바꾸고 다른 날짜는 보존한다. 후기만 수정하면 완료 상태는 유지하며, 달성 보고를 함께 한 경우에만 완료를 함께 반영한다. 기존 단일 DB 원본과 변경 이력을 재사용한다.

수정 후 잔디를 새로 게시한다. 제목 수정에도 과거 변경 이력은 DB에 남지만 이번 제목 수정 결과에는 별도 되돌리기 버튼을 제공하지 않는다. 다시 자연어로 수정할 수 있다. 후기·상태 변경은 기존 되돌리기 경로를 따른다.

## 검증

`qa/community-edit-language.mjs`: 날짜·연도·원문 보존·부정/가정·모델 실패. `qa/natural-edits.mjs`: 당사자 preview·대상 날짜·revision·필드 분리. `qa/edit-storage.sql`: 완료/휴식/후기가 있는 목표의 제목 수정 후 보존 및 동시 수정 충돌.

admin-dev 실제 사용자 프로필로 과거 목표 제목 수정→Only visible to you 확인→버튼 저장을 수행해 제목만 바뀌고 완료·후기·다른 날짜가 그대로인 것을 확인했다. QA 데이터는 원래 상태로 복원하고 복원 이력도 남겼다. 실제 사용자가 Slack에 남긴 과거 완료·후기 요청은 원문을 대조해 처리하고 대상 날짜 외 기록 불변을 검증했다. 개인 원문·스레드 식별자는 공개 문서에 포함하지 않는다.
