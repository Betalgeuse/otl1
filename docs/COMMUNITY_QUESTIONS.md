# v0.0.33 작은 자연어 질문 응답

Slack 일반 섹션·Starred·섹션 공유, 원씽 사용법, 주말 선택 참여 질문부터 지원한다. 질문 내용이 길거나 불분명하거나 확인된 범위를 벗어나면 답변 한계를 안내한다. 현재는 임의 웹 검색이나 모든 분야의 지식 답변을 제공하지 않는다.

기존 관리자/원씽 채널에서 질문 형태의 문장 또는 봇 멘션 메시지를 Qwen이 도움말 질문과 기록 요청으로 분류한다. ‘등록은 어떻게 해?’는 도움말, ‘책 읽기로 등록해줘?’는 기존 기록 확인 흐름으로 이어진다. 명확한 원씽 선언에는 추가 도움말 호출을 하지 않는다. 멘션 없는 질문도 질문 형태이면 처리한다.

모델은 승인된 도움말 주제만 선택하며 실제 답변 본문·출처는 확인된 지식에서 제공한다. 질문 경로에는 목표/후기/완료/설정을 수정하는 도구가 없다. 알 수 없는 주제나 API 실패가 목표 등록 확인으로 바뀌지 않는다. 범위 밖 질문, 변경 완료 주장, 임의 링크를 모델이 생성해도 그대로 발송하지 않는다.

Slack 답변 근거(2026-09-11 확인):
- https://slack.com/help/articles/360043207674-Organize-your-sidebar-with-custom-sections
- https://slack.com/help/articles/201331016-Star-channels-and-direct-messages
- https://slack.com/help/articles/29873996048019-Share-sidebar-sections-in-Slack

일반 개인 섹션과 Starred는 자동 전사 적용이 아니다. 유료 Slack의 별도 섹션 공유/사용자 그룹 연결과 구분하며, 커뮤니티 무료 운영이라는 사실만으로 Slack 요금제를 단정하지 않는다.

질문 처리에도 기존 사용자별 요청 한도를 사용하고 AI 호출에8초 제한을 둔다. 질문처럼 보이는 기록 요청은 도움말 분류 이후 기존 기록 분류가 추가 호출될 수 있다. 사람 자동 태깅/연결은 아직 구현하지 않았다.

검증: `qa/community-questions.mjs`가 기록 저장소 접근 금지·주제 범위·변경 요청 분기·실패 경계를 확인한다. 실제 admin-dev의 섹션/Starred 질문 스레드에서 답변을 확인하고 전후 전체 목표 이력이 같음을 대조한다. 배포 및 사용자 QA 근거는 `.omx/qa/questions/`에 보관한다.

## v0.0.34 운영 질문 안정화

‘주말 원씽도 필수야?’가 모델에 의해 범위 밖으로 분류된 실제 QA 사례를 보완했다. 주말의 필수·의무·선택을 묻는 명확한 질문은 확정된 정책으로 직접 답한다. 기록·변경 명령이 섞이면 기존 분류를 유지한다. 이 경로는 추가 LLM 호출이 없다.
